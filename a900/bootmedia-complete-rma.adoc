= Das defekte AFF A900 Boot-Medium wird nach dem manuellen Boot-Wiederherstellungsprozess an NetApp zurückgesendet.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn eine Komponente in Ihrem AFF A900 System ausfällt, senden Sie das ausgefallene Teil an NetApp zurück. Siehe die  https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"] Seite für weitere Informationen.

Senden Sie das fehlerhafte Teil wie in den dem Kit beiliegenden RMA-Anweisungen beschrieben an NetApp zurück.  https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"]Weitere Informationen finden Sie auf der Seite.
