= Das defekte Teil ist an NetApp - AFX 2K zurückzusenden.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn eine Komponente Ihres AFX 2K Speichersystems ausfällt, ist das defekte Teil an NetApp zurückzusenden. Siehe die https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"] Seite für weitere Informationen.
