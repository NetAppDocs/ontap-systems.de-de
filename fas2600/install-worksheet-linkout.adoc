= Das Cluster-Konfigurationsarbeitsblatt für Ihr FAS2600 System kann verwendet werden.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die link:https://docs.netapp.com/us-en/ontap/software_setup/gather_cluster_setup_information.html["Cluster-Konfigurationsdokument"^] kann genutzt werden, um standortspezifische IP-Adressen und weitere Informationen zu erfassen und zu dokumentieren, die bei der Konfiguration eines ONTAP Clusters für das FAS2600 System benötigt werden.
