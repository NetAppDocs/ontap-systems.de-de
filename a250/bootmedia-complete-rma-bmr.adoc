= Senden Sie das defekte Bootmedium an NetApp - AFF A250
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn eine Komponente in Ihrem AFF A250-System ausfällt, senden Sie das defekte Teil an NetApp zurück. Siehe die https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"] Seite für weitere Informationen.
