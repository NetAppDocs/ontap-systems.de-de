= Das defekte AFF A200 Bootmedium an NetApp zurücksenden
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Das defekte AFF A200 Bootmedium ist nach dem Austausch gemäß der mit dem Kit gelieferten RMA-Anleitung an NetApp zurückzusenden. Weitere Informationen sind auf der  https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"] Seite zu finden.
