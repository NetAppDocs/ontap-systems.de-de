= DS212C, DS224C oder DS460C Regal kalt austauschen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Beim Austausch eines Laufwerksgehäuses in einem Produktivsystem, in dem Festplatten in Betrieb sind, ist ein Kalt-Shelf-Austausch erforderlich. Dies ist ein unterbrechendes Verfahren, das das Anhalten der Controller im HA-Paar erfordert.

Dieses Verfahren gilt für Regale mit IOM12, IOM12B oder IOM12C Modulen.

Verwenden Sie den NetApp Knowledge Base Artikel https://kb.netapp.com/onprem/ontap/hardware/How_to_replace_a_shelf_chassis_using_a_cold_shelf_removal_procedure["So ersetzen Sie ein Shelf-Chassis durch ein Cold Shelf-Verfahren zum Entfernen"].
