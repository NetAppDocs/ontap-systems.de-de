= Das defekte AFF A800 Boot-Medium wird nach dem manuellen Boot-Wiederherstellungsprozess an NetApp zurückgesendet.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Nach Abschluss des manuellen Boot-Wiederherstellungsprozesses für ein ausgefallenes Boot-Medium in Ihrem AFF A800-System ist das defekte Teil an NetApp zurückzusenden. Details sind auf der  https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"] Seite zu finden.
