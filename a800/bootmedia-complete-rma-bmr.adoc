= Die ausgefallenen AFF A800 Bootmedien werden nach dem automatisierten Boot-Wiederherstellungsprozess an NetApp zurückgesendet.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Nach Abschluss des automatisierten Wiederherstellungsprozesses für ein defektes Boot-Medium in Ihrem AFF A800 System ist das defekte Teil an NetApp zurückzugeben. Details sind auf der  https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"] Seite zu finden.
