Wenn Sie im laufenden Betrieb weitere Shelfs zu einem A900 HA-Paar hinzufügen, müssen Sie die vorhandenen Shelfs neu verkabeln, um die Konnektivität über mehrere RoCE-fähige I/O-Module hinweg auszugleichen.

* Wenn Sie ein zweites Shelf im laufenden Betrieb hinzufügen, muss das erste Shelf über die Steckplätze 2 und 10 neu verkabelt werden. Für ein zweites Shelf wird davon ausgegangen, dass das vorhandene Shelf an jedem Controller mit einem RoCE-fähigen I/O-Modul in Steckplatz 2 verkabelt ist.
* Wenn Sie ein viertes Regal im laufenden Betrieb hinzufügen, muss das dritte Regal zwischen den Steckplätzen 1 und 11 neu verkabelt werden. Für ein viertes Regal wird davon ausgegangen, dass das dritte Regal an Steckplatz 1 jedes Controllers angeschlossen ist.


.Schritte
. Führen Sie einen der folgenden Schritte aus, wenn Sie ein zweites oder ein viertes Shelf im laufenden Betrieb hinzufügen.
+
** Wenn Sie während des laufenden Betriebs ein zweites Shelf hinzufügen, können Sie das erste Shelf über die RoCE-fähigen I/O-Module in Steckplatz 2 und Steckplatz 10 auf jedem Controller neu anschaffen.
+
... Verschieben Sie am Controller A das Kabel von Steckplatz 2 Port b (e2b) auf Steckplatz 10 Port b (e10b).
... Wiederholen Sie das gleiche Kabel, um es bei Controller B zu bewegen


** Wenn Sie ein viertes Shelf während des laufenden Betriebs hinzufügen, können Sie das dritte Shelf über die RoCE-fähigen I/O-Module in Steckplatz 1 und Steckplatz 11 auf jedem Controller umverteilen.
+
... Verschieben Sie am Controller A das Kabel von Steckplatz 1 Port b (e1b) zu Steckplatz 11 Port b (e11b).
... Wiederholen Sie das gleiche Kabel, um es bei Controller B zu bewegen




. Überprüfen Sie mit https://mysupport.netapp.com/site/tools/tool-eula/activeiq-configadvisor["Active IQ Config Advisor"^].
+
Wenn Verkabelungsfehler auftreten, befolgen Sie die entsprechenden Korrekturmaßnahmen.
