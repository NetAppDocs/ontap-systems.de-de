Wenn Sie ein zweites Shelf im laufenden Betrieb zu einem AFF A70- oder AFF A90-HA-Paar hinzufügen, müssen Sie das erste Shelf über die RoCE-fähigen E/A-Module in Steckplatz 11 und Steckplatz 8 an jedem Controller neu verkabeln.

Bei diesem Verfahren wird davon ausgegangen, dass das vorhandene Regal an jedem Controller mit einem RoCE-fähigen E/A-Modul in Steckplatz 11 verkabelt ist.

.Schritte
. Verkabeln Sie das erste Shelf über die RoCE-fähigen I/O-Module in Steckplatz 11 und Steckplatz 8 an jedem Controller neu.
+
.. Verlegen Sie am Controller A das Kabel von Slot 11 Port b (e11b) zu Slot 8 Port b (e8b).
.. Wiederholen Sie das gleiche Kabel, um es bei Controller B zu bewegen


. Überprüfen Sie mit https://mysupport.netapp.com/site/tools/tool-eula/activeiq-configadvisor["Active IQ Config Advisor"^].
+
Wenn Verkabelungsfehler auftreten, befolgen Sie die entsprechenden Korrekturmaßnahmen.
