= Die ausgefallenen FAS2820 Bootmedien werden nach dem automatisierten Boot-Wiederherstellungsprozess an NetApp zurückgesendet.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn eine Komponente Ihres FAS2820-Systems ausfällt, senden Sie das defekte Teil an NetApp zurück. Weitere Informationen sind auf der  https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"] Seite zu finden.
