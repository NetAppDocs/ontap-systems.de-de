= Das ausgefallene FAS2820-Bootmedium nach dem manuellen Boot-Wiederherstellungsprozess an NetApp zurücksenden
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Nachdem das Bootmedium in Ihrem FAS2820-System ausgetauscht wurde, ist das defekte Teil gemäß den in der mit dem Kit gelieferten RMA-Anleitung beschriebenen Anweisungen an NetApp zurückzusenden.

Senden Sie das fehlerhafte Teil wie in den dem Kit beiliegenden RMA-Anweisungen beschrieben an NetApp zurück.  https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"]Weitere Informationen finden Sie auf der Seite.
