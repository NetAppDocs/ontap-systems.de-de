= Das defekte AFF C400 Boot-Medium wird nach dem manuellen Boot-Wiederherstellungsprozess an NetApp zurückgesendet.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Das defekte AFF C400 Boot-Medium ist nach dem Austausch gemäß den mit dem Kit gelieferten RMA-Anweisungen an NetApp zurückzusenden.

Senden Sie das fehlerhafte Teil wie in den dem Kit beiliegenden RMA-Anweisungen beschrieben an NetApp zurück.  https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"]Weitere Informationen finden Sie auf der Seite.
