= Das defekte FAS2700 Bootmedium an NetApp zurückgeben
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Nachdem das Bootmedium auf Ihrem FAS2700-System ausgetauscht wurde, ist das defekte Teil gemäß den in den mit dem Kit gelieferten RMA-Anweisungen beschriebenen Vorgaben an NetApp zurückzusenden.

Weitere Informationen sind auf der  https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"] Seite zu finden. Das FAS2700 System unterstützt ausschließlich manuelle Bootmedien-Wiederherstellungsverfahren. Automatisierte Bootmedien-Wiederherstellung wird nicht unterstützt.
