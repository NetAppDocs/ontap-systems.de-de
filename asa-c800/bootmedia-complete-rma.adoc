= Senden Sie das fehlerhafte Bootmedium an NetApp - ASA C800 zurück
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn eine Komponente Ihres ASA C800 -Speichersystems ausfällt, senden Sie das defekte Teil an NetApp zurück.  Siehe die https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"] Weitere Informationen finden Sie auf der entsprechenden Seite.
