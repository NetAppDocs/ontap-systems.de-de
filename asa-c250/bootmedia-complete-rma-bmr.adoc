= Die ausgefallenen ASA C250 Bootmedien sind nach dem automatisierten Boot-Wiederherstellungsprozess an NetApp zurückzugeben.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn eine Komponente Ihres ASA C250-Systems ausfällt, senden Sie das defekte Teil an NetApp zurück. Siehe die https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"] Seite für weitere Informationen.
