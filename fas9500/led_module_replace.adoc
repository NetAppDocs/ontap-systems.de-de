= Das LED-USB-Modul im FAS9500 System ersetzen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Das LED-USB-Modul in Ihrem FAS9500-System bietet Konnektivität zu den Konsolenanschlüssen und zum Systemstatus. Der Austausch erfordert kein Werkzeug und führt zu keiner Unterbrechung des Betriebs.



[[step-1-replace-the-led-usb-module]]
== Schritt 1: Ersetzen Sie das LED-USB-Modul

.Schritte
. Entfernen Sie das alte LED-USB-Modul:
+
.Animation - LED-USB-Modul entfernen/installieren
video::bc46a3e8-6541-444e-973b-ae78004bf153[panopto]
+
image::../media/drw_9500_remove_replace_LED_mod.svg[Ersetzen Sie das LED-Modul]

+
[cols="20%,80%"]
|===


 a| 
image::../media/icon_round_1.png[Legende Nummer 1]
 a| 
Verriegelungsknopf



 a| 
image::../media/icon_round_2.png[Legende Nummer 2]
 a| 
USB-LED-Modul

|===
+
.. Wenn die Blende entfernt ist, suchen Sie das LED-USB-Modul an der Vorderseite des Gehäuses auf der unteren linken Seite.
.. Schieben Sie die Verriegelung, um das Modul teilweise auszuwerfen.
.. Ziehen Sie das Modul aus dem Schacht, um es von der Mittelplatine zu trennen. Lassen Sie den Steckplatz nicht leer.


. Installieren Sie das neue LED USB-Modul:
+
.. Das Modul wird so im Einbauschacht ausgerichtet, dass sich die Kerbe in der Ecke des Moduls in der Nähe des Schiebeverschlusses am Gehäuse befindet. Der Einbauschacht verhindert, dass das Modul verkehrt herum eingebaut wird.
.. Schieben Sie das Modul in den Schacht, bis es bündig mit dem Gehäuse sitzt.
+
Das Modul klickt hörbar, wenn es sicher befestigt und mit der Mittelplatine verbunden ist.
