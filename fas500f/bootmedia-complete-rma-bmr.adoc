= Senden Sie das defekte Bootmedium an NetApp - FAS500f
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn eine Komponente Ihres FAS500f-Systems ausfällt, senden Sie das defekte Teil an NetApp zurück. Siehe die https://mysupport.netapp.com/site/info/rma["Rückgabe und Austausch von Teilen"] Seite für weitere Informationen.
